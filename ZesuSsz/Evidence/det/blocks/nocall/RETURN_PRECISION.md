# Return precision audit

The generator identifies every return address from the pinned call index.
It states x1, x5, x10, and x11 with BitsShape 64 at those addresses.
The audit regenerated every no-call entry and copied successor predicate.
All staged predicates and eight closed whole-block proofs compiled together in 16 seconds.
The project check-fast gate passed in 70 seconds.

Blocks with a callee keep memory atoms open. Sealed memory in other blocks retains its ZesuSealed coverage instance.
The generator accepts --extra-leader and preserves the pinned instruction partition and final successors.
The 15754 split proof runs are separate work.
