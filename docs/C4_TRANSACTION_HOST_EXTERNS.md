# C4 transaction host externs for review

The [Q18 manifest](../generated/evm-sail-coq/transactions/SOURCE.json) fixes the seven reached Sail declarations. Each root reaches the five scratch operations and `scratch_keccak256`. The roots are `decode_legacy_tx`, `decode_access_list_tx`, `decode_fee_market_tx`, `decode_blob_tx`, `decode_set_code_tx`, and `rlp_decode_tx`. Only `rlp_decode_tx` reaches `stateless_input_keccak256`. Reachability means that the generated closure contains a call. It does not mean that every execution calls the extern.

- `host_scratch_reserve` (`sail/host/scratch.sail:14`): `forall 'off 'len, 0 <= 'off & 'off <= scratch_region_bound & 0 <= 'len & 'len <= scratch_region_bound. (int('off), int('len)) -> bool`. The body must report whether the requested range fits. Sail asserts the returned Boolean. A false value stops decoding. No retained C2 field uses that Boolean as a value.
- `host_scratch_store_byte` (`scratch.sail:25`): `forall 'off, 0 <= 'off & 'off <= scratch_region_bound. (int('off), byte) -> ScratchSliceLength('off + 1)`. The body must store the byte at the explicit offset and return the new scratch length. Sail writes that length into `scratch_arena`. No retained C2 field reads the returned length directly.
- `host_scratch_store_stateless_input` (`scratch.sail:33`): `forall 'dst 'off 'len, 0 <= 'dst & 'dst <= scratch_region_bound & stateless_input_valid_range('off, 'len). (int('dst), StatelessInputSliceFields('off, 'len)) -> ScratchSliceLength('dst + 'len)`. The body must copy the exact input bytes to scratch and return the new scratch length. No retained C2 field reads those scratch bytes directly.
- `host_scratch_store_word` (`scratch.sail:106`): `forall 'off 'len, 0 <= 'off & 'off <= scratch_region_bound & 0 <= 'len & 'len <= 32. (int('off), word, int('len)) -> ScratchSliceLength('off + 'len)`. The body must write the low `len` bytes in big-endian order and return the new scratch length. The legacy signing path can call it. No retained C2 field reads its result directly.
- `host_scratch_truncate` (`scratch.sail:119`): `scratch_pointer -> unit`. The body must discard scratch bytes from the mark onward and preserve earlier bytes. The return value carries no retained C2 field.
- `scratch_keccak256` (`crypto.sail:57`): `ScratchSlice -> hash`. The body must hash the exact scratch preimage and return its Keccak-256 digest. Each decoder stores the digest in `signing_hash`, which C2 omits. A changed digest has no direct value path to a retained C2 field.
- `stateless_input_keccak256` (`crypto.sail:55`): `StatelessInputSlice -> hash`. The body must hash the 64-byte public-key body and return its Keccak-256 digest. The dispatcher derives `sender` from that digest. C2 omits `sender`, so the digest has no direct value path to a retained C2 field.

The [Rocq lemma](../ZesuSsz/Compliance/C4ProjectionAudit.v) proves that changing `sender` and `signing_hash` leaves `TransactionProjection` unchanged after record construction. It does not prove independence for the complete `rlp_decode_tx` action. The generated dispatcher calls the public-key hash before it reads the transaction type. Each decoder calls the scratch hash before its final integer decodes. The seven externs are impure monadic actions. C4 must guarantee completion on approved inputs and the specified scratch writes and cursor updates. C4 must also guarantee preservation of the input bytes and unrelated Sail state. A bridge must relate the Q18 `evm_rlp_decode_tx_types.TransactionFields` type to the C2 `EvmSail.evm_decoder_types.TransactionFields` type. No extern body or state-preservation premise exists in this note.
